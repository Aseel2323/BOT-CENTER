# BOT CENTER — Premium Store

متجر عربي RTL لعرض 20 روبوت تداول، مبني بملفات HTML وCSS وJavaScript ثابتة.

## الملفات
- `index.html` واجهة المتجر.
- `styles.css` التصميم المتجاوب.
- `products.js` بيانات المنتجات والأسعار.
- `app.js` البحث والتصفية وتفاصيل المنتجات والطلب عبر تيليغرام.
- `assets/` صور المنتجات الأصلية التي أرسلها صاحب المتجر.

## التشغيل
افتح `index.html` في المتصفح أو ارفع محتويات المجلد إلى GitHub Pages أو Netlify.

## روابط المتجر
- الدعم: https://t.me/Bot_SupportFX
- قناة المنتجات: https://t.me/BotSTORFX

## تحديث البيانات
عدّل `products.js` لتغيير المواصفات أو الأسعار أو صور المنتجات. كل منتج يستخدم `image` لاسم الصورة داخل `assets/`.

## ملاحظات مهمة
- المتجر واجهة ثابتة؛ لا يحتوي حالياً على لوحة إدارة أو قاعدة بيانات أو دفع إلكتروني أو تسجيل دخول.
- أزرار الطلب تفتح محادثة الدعم في تيليغرام مع نص طلب مُجهز. إتمام الطلب والدفع يتمان عبر فريق الدعم.
- تم إدخال الأسعار حسب التفاصيل التي أرسلها صاحب المتجر. بوت النمر TIGER هو نفسه NMER.
- لا توجد وعود بضمان الأرباح؛ التداول ينطوي على مخاطر وقد يؤدي إلى خسارة رأس المال.
